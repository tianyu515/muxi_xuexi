一个简单web的完整代码
```go
package main
import(
    "fmt"
    "net/http"
)
func hello(w http.ResponseWriter,r *http.Request) {
    fmt.Fprintf(w,"你好，小猪")
    fmt.Println(r.Method)
}
func main() {
    http.HandleFunc("/hello",hello)
    err := http.ListenAndServe(":8080",nil)
    if err != nil {
        fmt.Println("创建失败",err)
        return
    }
}
```
- 之前学习是作为一个客户端去发请求，现在是作为服务端去接受请求并返回响应
- 首先需要去定义一个函数，接受的两个参数一个是w(写响应的入口)，一个是r(指向Request的地址)，来接受客户端传来的信息
  如r.Method,r.URL.Path。这两个参数不是我们去添加的，而是服务器调用函数时自己生成的，所以调用时只用写hello即可
- 其次是要去注册路由，告诉服务器，当用户访问这个路径时应该调用什么函数
- 最后就是去让服务器开始工作，让go程序启动监听8080端口，nil就是使用初始的路由器。为什么会返回错误呢，因为程序不是一开始就全部执行完，而是一直等待用户发请求过来，就会出选错误。
